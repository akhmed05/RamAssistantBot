# RamAssistantBot

Telegram-бот на aiogram 2: меню `/start`, ответы AI, отправка заявки через
Google Apps Script и PDF. YouTube-саммари сохраняет существующее поведение:
возвращает заглушку, без загрузки видео и реального AI-резюме.

## Подготовка

Используйте Python 3.11: для зависимости `aiohttp<3.9` доступны готовые колёса.
Из корня репозитория:

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r RamAssistantBot/requirements.txt
.venv/bin/python -m pip check
```

`openai==1.3.7` используется через `AsyncOpenAI.chat.completions.create`.
`httpx==0.27.2` закреплён, потому что OpenAI SDK этой версии передаёт
аргумент `proxies`, удалённый в httpx 0.28.

## Конфигурация

Задавайте значения через переменные окружения или секреты среды.
Не записывайте реальные токены в репозиторий.
В `.env.example` приведены только имена переменных и пустые значения.
Приложение не загружает `.env` автоматически: настройте переменные процесса
или Railway Variables. `.gitignore` исключает локальные `.env`, ключи,
виртуальные окружения и Python-кэш.

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram; требуется только при запуске |
| `OPENAI_API_KEY` | Ключ OpenAI для модели `gpt-4`; без ключа остальные функции доступны |
| `RAM_OPENAI_API_KEY` | Альтернатива для облачной среды, где имя секрета `OPENAI_API_KEY` зарезервировано |
| `GOOGLE_SCRIPT_URL` | Необязательное переопределение существующего URL Apps Script |
| `BOT_PROXY` | Необязательный HTTP-прокси Telegram; по умолчанию используется `HTTPS_PROXY` |

Для внешних функций требуется доступ к `api.telegram.org`, `api.openai.com`,
`script.google.com` и `script.googleusercontent.com`. Доступность API,
модели и Apps Script без реальных учётных данных не проверяется.

## Тесты без токенов

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m unittest discover -s tests -v
```

Тесты не запускают polling и не отправляют сообщения или заявки.
Они блокируют сетевые подключения, проверяют маршрутизацию искусственных
Telegram updates, используют локальный `httpx.MockTransport` для настоящего
OpenAI SDK и имитируют HTTP-заявки. Покрыты успешные ответы, ошибки API,
таймауты, пустые и длинные ответы, валидация URL и заявок, меню и PDF.
Импорт `main` не создаёт бота и не требует `BOT_TOKEN`.

В подготовленной облачной среде вместо `.venv/bin/python` используйте
`/workspace/.venvs/ramassistant/bin/python`.

## Запуск после подтверждения

Запуск выполняется отдельно, после проверки изменений и явного подтверждения:

```bash
.venv/bin/python RamAssistantBot/main.py
```

PDF ищется относительно `main.py`, независимо от рабочей папки.
AI и заявка используют принудительный ответ на сообщение-приглашение бота.
Как и в исходной версии, `skip_updates=True` удаляет накопившиеся Telegram
updates при запуске.
Второй процесс polling для того же токена одновременно запускать нельзя.

## Railway

После проверки Pull Request настройте сервис Railway:

| Настройка | Значение |
| --- | --- |
| Root Directory | `/RamAssistantBot` внутри репозитория |
| Python | `3.11.17` (указан в `RamAssistantBot/.python-version`) |
| Установка зависимостей | `pip install -r requirements.txt` |
| Start Command | `python main.py` |
| Replicas | `1` |
| HTTP healthcheck и публичный домен | Не требуются: бот использует polling, HTTP-сервера нет |

В Railway Variables добавьте `BOT_TOKEN` и, для AI, `OPENAI_API_KEY`
или `RAM_OPENAI_API_KEY`. При необходимости переопределите `GOOGLE_SCRIPT_URL`.
Убедитесь, что сборщик использует Python 3.11, а не новую версию по умолчанию.
Не запускайте деплой и не включайте автоматическое развёртывание ветки с
исправлениями до явного подтверждения. Настройки панели Railway и реальный
деплой в этой среде не проверялись.

## Ограничения проверки

Все тесты выполняются без реальных токенов. Они не подтверждают доступность
модели `gpt-4`, авторизацию Telegram или работу реального Apps Script.
PDF-тест проверяет путь и передачу файла, а не его полноценность:
текущий `media/info.pdf` — некорректная заглушка размером 20 байт.
Перед развёртыванием замените её действительным документом для пользователей.
YouTube-саммари остаётся исходной текстовой заглушкой.
