# RAM v2 — менеджер Wildberries в Telegram

Новая версия бота, написана с нуля. Старая версия лежит в папке `RamAssistantBot/`
и не тронута.

## Что бот умеет сейчас

| Функция | Как работает |
| --- | --- |
| **Два кабинета** | Переключение кнопкой. Данные и себестоимость у каждого кабинета свои. |
| **📊 Юнит-экономика** | За 7, 14 или 30 дней. Короткий итог в чате и Excel со всеми артикулами: выручка, логистика, хранение, штрафы, реклама, себестоимость, налог, прибыль, маржа, ДРР, ROI. |
| **💰 Себестоимость** | Бот даёт Excel-шаблон со списком ваших артикулов. Вы заполняете и отправляете файл обратно в чат. |
| **Налог** | Команда `/tax 6` задаёт 6% от выручки. `/tax 0` — без налога. |
| **Доступ** | Бот отвечает только владельцу (по Telegram ID) и только в личном чате. |

Пока бот **только читает** данные WB и ничего в кабинете не меняет.

## Откуда берутся цифры

- **Продажи, возвраты, логистика, хранение, штрафы, удержания.** Ежедневный отчёт
  о реализации WB, тот же, что в разделе финансовых отчётов кабинета. WB выкладывает
  его на следующий день, поэтому период заканчивается вчерашним днём.
- **Реклама по каждому артикулу.** Статистика рекламных кампаний WB.
- **Себестоимость и налог.** Их вводите вы.

Формула прибыли артикула:
к перечислению − логистика − хранение − штрафы − приёмка − удержания − реклама −
себестоимость × (продано − возвраты) − налог.

Есть расходы, которые WB не привязывает к конкретному артикулу, например часть
хранения. Они показываются отдельной строкой и вычитаются из общей прибыли кабинета.

## Что нужно настроить (один раз)

### 1. Токен WB для каждого кабинета

В кабинете продавца WB, в настройках, есть раздел «Доступ к API». Создайте там токен:

- категории: **Статистика** и **Продвижение**;
- отметьте «Только чтение»: на этом этапе бот ничего не меняет.

Токен для кабинета Марины делается так же, только в её кабинете.

### 2. Переменные в Railway

| Переменная | Что вписать |
| --- | --- |
| `BOT_TOKEN` | токен Telegram-бота от @BotFather |
| `RAM_OWNER_IDS` | ваш Telegram ID (только цифры) |
| `RAM_WB_1_TOKEN` | токен WB первого кабинета |
| `RAM_WB_1_NAME` | название, например `Ахмад` |
| `RAM_WB_2_TOKEN` | токен WB второго кабинета |
| `RAM_WB_2_NAME` | название, например `Марина` |
| `RAM_DB_PATH` | `/data/ram.sqlite3` (если подключён Volume) |

Ключи вписывайте **только** в Railway. В Telegram, чаты и GitHub их отправлять нельзя.

### 3. Настройки сервиса в Railway

- Branch: `v2-ram-manager`
- Root Directory: `/ram_v2`
- Start Command: `python main.py`
- Volume с путём монтирования `/data`. Без него после каждого перезапуска будет
  теряться введённая себестоимость.

Один токен Telegram-бота может работать только в одном запущенном сервисе.
Если тот же бот запущен где-то ещё, его нужно остановить.

## Проверка после запуска

1. `/start`: должно появиться меню.
2. «📊 Юнит-экономика» → «30 дней»: придёт итог и Excel.
3. «💰 Себестоимость» → «Скачать шаблон»: заполните и пришлите файл.
4. `/tax 6` (или ваша ставка), затем повторите отчёт.
5. «🔁 Сменить кабинет» → второй кабинет → повторите отчёт.

## Что дальше по плану

1. **Реклама.** Ежедневная проверка ДРР по артикулам. Бот сам меняет ставки в
   пределах ±20% и держит дневной лимит. Всё, что больше, приходит вам на
   подтверждение кнопкой.
2. **Поставки.** Прогноз, когда закончатся остатки на каждом складе. Предложение,
   что и куда везти. Уведомление о бесплатной приёмке.
3. **Карточки.** Создание карточек, заполнение характеристик и описаний.

## Для разработчика

```bash
cd ram_v2
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
```

Тесты работают без сети. Ответы WB в них подменены.
